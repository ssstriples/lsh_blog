# 📝 요구조건 명세서 (초안) — lsh_blog

> AI 초안 생성 → 사람 검수 단계의 산출물 (1차 개략 버전)

## 1. 목적 / 배경

- 개인 기술 블로그를 운영하며 학습/개발 기록을 축적하고, AI를 활용한 명세서 작성 방법론 자체를 콘텐츠화한다.
- `onggi-shop` 프로젝트에서 검증된 인증/CRUD/관리자 아키텍처를 재사용하여 개발 리소스를 절약한다.

## 3. 기능 목록 (MoSCoW)

### Must Have (필수, MVP)
- 관리자 로그인 (JWT 기반, 소셜 로그인 제외)
- 게시글 CRUD (제목/본문/썸네일/카테고리/태그)
- 카테고리 목록/상세, 태그 목록/상세
- 게시글 목록 페이지네이션 / 정렬(최신순, 인기순)
- 댓글 CRUD (대댓글 미포함 1차)
- 검색 (제목+본문 LIKE 검색)
- 조회수 카운트
- 다크모드
- 반응형 레이아웃 (모바일 대응)
- 기본 SEO (메타 태그, OG 이미지, sitemap.xml, robots.txt)

### Should Have (중요, 2차)
- 대댓글 (댓글 계층 구조)
- 게시글 좋아요
- 관리자 대시보드 (통계: 총 조회수, 인기글 Top5, 최근 댓글)
- 이미지 업로드 (Cloudinary)
- 임시저장(Draft) 기능
- RSS 피드 (`/rss.xml`)
- 코드 하이라이팅 (Shiki/PrismJS)

### Could Have (있으면 좋음, 3차)
- 방명록 게시판
- 뉴스레터 구독 (이메일)
- AI 명세서 자동 생성 파이프라인 연동 (관리자 글쓰기 화면 내 "AI 초안 생성" 버튼)
- 방문 통계(GA4) 연동
- 댓글 알림 (이메일)
- 소셜 로그인 (댓글 작성자용)

### Won't Have (이번 범위 제외)
- 다중 작성자(멀티 유저 CMS)
- 유료 구독/멤버십
- 실시간 채팅

## 4. 비기능 요구사항

| 구분 | 요구사항 |
|------|----------|
| 성능 | 게시글 목록 페이지 LCP 2.5초 이내, 이미지 최적화(next/image) |
| 보안 | 관리자 인증 JWT 이중 시크릿, Rate Limiting, XSS 방지(DOMPurify), Helmet 보안 헤더 |
| SEO | 서버사이드 렌더링(SSR/ISR), 구조화 데이터(JSON-LD), sitemap 자동 생성 |
| 접근성 | 시맨틱 마크업, 다크모드 대비율 WCAG AA |
| 운영 | CI/CD 자동 배포, 에러 로깅(winston), 백업 정책 |

## 5. 범위 밖 (Out of Scope)

- 다중 저자/팀 블로그 운영 기능
- 결제/후원 기능
- 모바일 네이티브 앱
