# 🖥️ 페이지 와이어프레임 — lsh_blog

> ⚠️ **2차 개정 (2026-08-07)**: `/admin/posts/*` (글쓰기)를 일반 로그인 유저 누구나 쓸 수 있는
> `/posts/new`, `/posts/[id]/edit`, `/my/posts`로 이동. `/admin/*`는 모더레이션 전용으로 축소.

## 전체 페이지 맵

```
/ (홈 - 최신글 목록)
│
├── /posts/[slug]              게시글 상세
├── /posts/new                 새 글 작성 🔒 (로그인 유저 누구나)
├── /posts/[id]/edit           글 수정 🔑 (본인 글만)
├── /category/[slug]           카테고리별 목록
├── /tag/[slug]                태그별 목록
├── /users/[id]                작성자 공개 프로필 (해당 유저의 게시글 목록)
├── /search?q=                 검색 결과
├── /about                     소개 페이지
├── /login                     로그인
├── /signup                    회원가입 🆕
├── /rss.xml, /sitemap.xml
│
├── /my (로그인 유저 전용, 마이페이지) 🆕
│   ├── /my/posts               내가 쓴 글 목록 (검색/필터/상태 배지)
│   ├── /my/posts/[id]/edit     → /posts/[id]/edit 로 연결
│   └── /my/profile             내 프로필 수정 / 회원 탈퇴
│
└── /admin (ADMIN 전용 — 모더레이션 및 회원 관리)
    ├── /admin                 대시보드 (전체 유저/게시글/조회수 통계)
    ├── /admin/posts           전체 게시글 목록 (모더레이션, 강제 삭제/비공개)
    ├── /admin/comments        전체 댓글 관리 (스팸/악성 댓글 삭제)
    ├── /admin/users           회원 목록 / 정지·해제 🆕
    └── /admin/categories      카테고리 관리
```

## Header (공통)

```
┌──────────────────────────────────────────────────────────────┐
│ [로고]  [카테고리▼] [검색 🔍]   [글쓰기 ✏️]  🌙  [로그인/마이페이지] │
└──────────────────────────────────────────────────────────────┘
```

> 💡 "글쓰기 ✏️" 버튼은 **로그인한 모든 유저**에게 노출됩니다 (기존에는 "관리자" 배지만 노출).
> 비로그인 상태에서 클릭 시 `/login`으로 리다이렉트.

## 새 글 작성 / 수정 (/posts/new, /posts/[id]/edit) — 🔒 로그인 유저 전용

> 기존 `/admin/posts/new`에서 이동. **관리자 여부와 무관하게 로그인만 하면 접근 가능.**
> 수정 페이지(`/posts/[id]/edit`)는 **작성자 본인**이 아니면 403 페이지로 리다이렉트.

```
┌──────────────────────────────────────────────────────┐
│ 제목 [_______________________]                          │
│ 슬러그 [_____________]  카테고리 [▼]  태그 [multi-select] │
│ 썸네일 업로드 [이미지]                                     │
│ ──────────────────────────────────────────────────── │
│ [TipTap 리치 에디터 툴바: B I U H1 H2 코드 표 이미지 등]   │
│ ┌──────────────────────────────────────────────────┐ │
│ │  본문 작성 영역                                     │ │
│ └──────────────────────────────────────────────────┘ │
│ [임시저장 자동 표시: "3분 전 저장됨"]                       │
│ [AI 초안 생성] [임시저장] [발행하기]                        │
└──────────────────────────────────────────────────────┘
```

> 삭제하거나 비공개 전환하는 **모더레이션 액션만** 수행합니다.
