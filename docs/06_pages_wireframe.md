# 🖥️ 페이지 와이어프레임 — lsh_blog

## 전체 페이지 맵

```
/ (홈 - 최신글 목록)
│
├── /posts/[slug]              게시글 상세
├── /category/[slug]           카테고리별 목록
├── /tag/[slug]                태그별 목록
├── /search?q=                 검색 결과
├── /about                     소개 페이지
├── /login                     관리자 로그인
├── /rss.xml, /sitemap.xml
│
└── /admin (ADMIN 전용)
    ├── /admin                 대시보드 (통계)
    ├── /admin/posts           게시글 목록
    │   ├── /admin/posts/new
    │   └── /admin/posts/[id]/edit
    ├── /admin/categories      카테고리 관리
    ├── /admin/tags            태그 관리
    └── /admin/comments        댓글 관리
```

## Header (공통)

```
┌──────────────────────────────────────────────────────┐
```
